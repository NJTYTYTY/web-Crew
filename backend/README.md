# Backend (`/backend`)

Node.js + Express.js + TypeScript + Drizzle ORM + PostgreSQL backend service for:
* **Authentication** (`username` & `password` with `bcrypt` + `jsonwebtoken`)
* **Storefront & Admin CRUD APIs** (validated with `zod`)
* **IQ-Bank Dynamic QR & HMAC-SHA256 Webhook Verification** (`/api/webhooks/iqbank`)
